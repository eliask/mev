SOURCE-FIRST IDENTITY GATE:
1. Read the entire proposition source_text and freeze the most specific target
   actually stated there before reading the official object. Scan subordinate
   clauses after a colon, comma, or "että/that" clause: a concrete measure or
   object there remains a source target even when the sentence starts with a
   broad value or desire. For example, “vaikuttamaan syntyvään vanhuslakiin:
   siihen on kirjattava mm. hoitajavahvuus” explicitly targets staffing.
2. Do not import an object's bill title, section number, instrument, direction,
   or technical detail into a vague source target. A source target may remain
   short (for example “hoitajavahvuus”); the object supplies only the candidate
   comparison, not missing source specificity.
3. A generic value, population, institution, broad domain, or slogan with no
   concrete source measure/object is not bounded. If the source is generic and
   the object specific, use UNRESOLVED, not SAME_POLICY_OBJECT. Broad topic
   overlap is not identity.
4. Use SAME_MATTER only when the same formal matter ID is explicit in both
   source contexts. Use SAME_POLICY_OBJECT only when the frozen source target
   and official object are the same substantive policy object. Use
   PARTIAL_COMPONENT when the explicit source target is a supported component
   of the larger official object; use EXACT only for the same bounded object.
5. Use REJECTED only when the source itself is sufficiently specific and the
   official object explicitly concerns a materially different object/law area.
   Otherwise use UNRESOLVED.

For a positive relation identity_basis must be REVIEWED_SOURCE_LINK or
EXPLICIT_TARGET_AND_MATTER. normalized_target must paraphrase the frozen
source target, never a bare bill ID or object-only invention. Copy matter_id
exactly from the official object. For REJECTED/UNRESOLVED use null target and
UNRESOLVED identity where required.

Assess action alignment separately. Broad, positional, process, collective,
and outcome text is RELATED at most, never ALIGNED or CONTRARY. Those require
explicit self-scoped observable action, action kind, and matching actor/action
evidence. A first author/signatory is not automatically a drafter; a raw JAA
or EI ballot has no policy meaning without the complete motion and alternatives.

bounded_claim and rationale to one brief sentence of at most 120 characters.
